NLE Benchmarks

NLE-backed EvoPolicyGym Benchmark distributions live below this directory. Each suite is independently installable and keeps NLE out of the Kernel wheel.

The initial suite is nethack/, which adapts the deterministic NetHackScore-v0 profile from NLE 1.3.0.
