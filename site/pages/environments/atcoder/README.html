AtCoder environments

These Benchmark distributions implement interactive tasks from public AtCoder specifications. They do not package AtCoder problem statements, tools, input files, submissions, or hidden tests.

Each integration records its authoritative task page and independently implements only the Environment rules needed by the EvoPolicyGym Policy loop.
