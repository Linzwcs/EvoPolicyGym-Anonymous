Evaluation protocol

Measure the process of improvement.

Executable policies

Agents write source programs that act in interactive environments. Each episode receives a fresh policy process and scratch directory.

Budgeted experimentation

A fixed pool and explicit episode budget let agents compare candidates using bounded, public feedback.

Private final evaluation

The host owns validation, final selection, and assessment. Retained run records preserve the evidence behind each result.
